# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Sentora-2027 (Ubuntu 26.04) | :white_check_mark: |
| Sentora-2027 (Debian 13) | :white_check_mark: |
| Sentora-2027 (AlmaLinux 10, Rocky Linux 10) | :white_check_mark: |
| Sentora 2.0.2 and older | :x: |

Extra PHP versions follow PHP's own support dates: PHP 8.2 gets security fixes until 31 December 2026, PHP 8.3 until 31 December 2027, PHP 8.4 until 31 December 2028 and PHP 8.5 until 31 December 2029.

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

Report it privately: [open a private report](https://github.com/RusTus/sentora-core-2027/security/advisories/new) (the repository's **Security** tab, **Report a vulnerability**). This covers the installer files too. Include:

- the module or page affected
- the steps to reproduce it, and the account type needed (client, reseller or administrator)
- what an attacker could reach or change

You'll get a reply when the report has been reviewed. Fixes are listed in the [change log](CHANGELOG.md) once they're released.
